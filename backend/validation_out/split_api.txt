## 第 2 章 通用约定

**基础约定**

| 项 | 约定 |
| --- | --- |
| 版本前缀 | `/api/v1/` |
| 请求体格式 | `application/json`，字段命名 `snake_case` |
| 时间格式 | ISO 8601 + UTC，如 `2025-01-13T02:15:00Z` |
| 空值 | 返回 `null`，不省略字段 |
| 成功响应 | 不套信封，直接返回资源对象或分页对象 |
| 失败响应 | 统一错误体，见下 |
| 幂等 | 写操作支持 `Idempotency-Key` 请求头，相同 Key 在 24 小时内返回首次结果 |

**分页约定**

列表接口统一使用 `page`（从 1 起）+ `page_size`（默认 20，上限 100），响应结构为：

```json
{
  "items": [],
  "page": 1,
  "page_size": 20,
  "total": 0
}
```

**统一错误体**

```json
{
  "code": "RPT001",
  "message": "时间范围超过 31 天",
  "detail": null
}
```

**状态码分界**

| 状态码 | 含义 |
| --- | --- |
| 400 | 请求本身不合法（缺字段、类型错误、格式错误） |
| 401 | 未登录或凭证失效 |
| 403 | 已登录但无权限 |
| 404 | 资源不存在 |
| 409 | 状态冲突或并发冲突 |
| 422 | 请求合法但业务校验不通过 |
| 429 | 触发外部依赖限流 |
| 502 | 外部依赖失败 |

**条件约定**

- 入站回调（Webhook）：不适用。本期无支付 / 消息类服务的入站回调，飞书为出站调用。
- 文件上传 / 下载：不适用。本期无附件、头像、导入导出文件。
- 实时接口：不适用。汇总进度页通过轮询 `GET /api/v1/aggregations/{id}` 获取任务状态，不使用 SSE / WebSocket。

## 第 3 章 鉴权与授权

**认证方式**

账号密码注册登录，登录成功后签发 JWT 凭证。除注册与登录接口外，所有接口需在请求头携带：

```bash
Authorization: Bearer <jwt_token>
```

凭证失效时返回 401，前端跳回登录页。密码以哈希形式存储，不落明文。

**角色与可见范围**

| 角色 | 可见范围 |
| --- | --- |
| owner（群聊归属人） | 可绑定 / 解绑群聊、查看与自己有关的周报、编辑草稿、导出到飞书 |
| member | 只读自己被汇总到的条目，不能改他人草稿 |

未登录用户只能看到登录页。

**授权规则**

| 资源 | 规则 |
| --- | --- |
| 群聊配置 | 仅归属人（owner）可绑定 / 解绑 |
| 汇总任务 | 仅归属人可触发与重试 |
| 周报草稿 | owner 可读写；member 只读自己被汇总到的条目 |
| 导出记录 | 仅返回与当前用户有关的记录 |

## 第 5 章 错误码表

| 错误码 | HTTP | 含义 | 触发场景 |
| --- | --- | --- | --- |
| `AUTH001` | 400 | 请求参数不合法 | 注册 / 登录缺字段或格式错误 |
| `AUTH002` | 401 | 账号或密码错误 | 登录校验失败 |
| `AUTH003` | 401 | 凭证缺失或失效 | 未携带 JWT 或 JWT 过期 |
| `AUTH004` | 403 | 无权限访问该资源 | member 尝试编辑他人草稿 |
| `AUTH005` | 409 | 邮箱已被注册 | 注册时邮箱重复 |
| `GRP001` | 404 | 群聊不存在 | 绑定的群聊 id 不存在 |
| `GRP002` | 403 | 非群聊归属人 | 非 owner 触发汇总或解绑 |
| `AGG001` | 422 | 时间范围超过 31 天 | `end_at - start_at > 31 天` |
| `AGG002` | 422 | 时间范围不合法 | `end_at` 早于 `start_at` |
| `AGG003` | 404 | 汇总任务不存在 | 查询的汇总 id 不存在 |
| `AGG004` | 409 | 汇总任务状态不允许该操作 | 对非 `failed` 任务触发重试 |
| `AGG005` | 422 | 群聊在选定范围内没有消息 | 汇总结果为空，返回空态 |
| `RPT001` | 404 | 周报草稿不存在 | 查询的草稿 id 不存在 |
| `RPT002` | 409 | 草稿状态不允许该操作 | 对 `exported` 草稿再次导出 |
| `RPT003` | 422 | 汇总任务未成功，无法生成草稿 | 汇总任务非 `succeeded` |
| `EXP001` | 429 | 飞书侧限流 | 飞书返回限流，需退避重试 |
| `EXP002` | 502 | 飞书导出失败 | 飞书接口调用失败 |
| `EXP003` | 404 | 导出记录不存在 | 查询的导出 id 不存在 |
| `SYS001` | 500 | 服务内部错误 | 未预期的服务端异常 |

## 第 7 章 接口详情

### POST /api/v1/auth/register

**用途**：以账号密码注册新用户，成功后返回用户信息。

**PRD 来源**：FR-01

**鉴权**：不需要登录。

**请求体**

| 字段 | 类型 | 必填 | 约束 |
| --- | --- | --- | --- |
| name | string | 是 | 长度 1–50 |
| email | string | 是 | 邮箱格式，全局唯一 |
| password | string | 是 | 长度 8–64，服务端以哈希形式存储 |

**响应**

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 用户 id，形如 `usr_001` |
| name | string | 姓名 |
| email | string | 邮箱 |
| created_at | string | ISO 8601 UTC |

```json
{
  "id": "usr_001",
  "name": "张伟",
  "email": "zhangwei@example.com",
  "created_at": "2025-01-13T02:15:00Z"
}
```

**错误码**：`AUTH001`、`AUTH002`、`AUTH003`

**幂等性**：写操作，支持 `Idempotency-Key` 请求头，相同 Key 在 24 小时内返回首次结果。

**业务规则**：邮箱重复时返回 `AUTH002`；密码不落明文，仅存哈希。

**关联验收标准**：AC-01

### POST /api/v1/auth/login

**用途**：账号密码登录，返回 JWT 凭证。

**PRD 来源**：FR-01

**鉴权**：不需要登录。

**请求体**

| 字段 | 类型 | 必填 | 约束 |
| --- | --- | --- | --- |

**响应**

| 字段 | 类型 | 说明 |

| expires_in | integer | 有效期秒数，固定 86400 |
| user | object | 用户对象，字段同注册响应 |

```json
{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.payload.signature",
  "token_type": "Bearer",
  "expires_in": 86400,
  "user": {
    "id": "usr_001",
    "name": "张伟",
    "email": "zhangwei@example.com",
    "created_at": "2025-01-13T02:15:00Z"
  }
}
```

**错误码**：`AUTH001`、`AUTH004`

**幂等性**：写操作，支持 `Idempotency-Key` 请求头，相同 Key 在 24 小时内返回首次结果。

**业务规则**：凭证错误统一返回 `AUTH004`，不区分账号不存在与密码错误。

**关联验收标准**：AC-01

### POST /api/v1/aggregations

**用途**：绑定群聊并选定时间范围，触发汇总任务。

**PRD 来源**：FR-02

**鉴权**：需要登录，角色 owner。

**请求体**

| 字段 | 类型 | 必填 | 约束 |
| --- | --- | --- | --- |
| chat_group_id | string | 是 | 必须为当前用户归属的群聊 |
| start_at | string | 是 | ISO 8601 UTC |
| end_at | string | 是 | ISO 8601 UTC，且晚于 `start_at` |

**响应**

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 汇总任务 id，形如 `agg_001` |
| chat_group_id | string | 群聊 id |
| start_at | string | 时间范围起 |
| end_at | string | 时间范围止 |
| status | string | `running` / `succeeded` / `failed` |
| message_count | integer | 汇总到的消息数，未完成时为 0 |
| is_empty | boolean | 范围内无消息时为 `true` |
| created_at | string | ISO 8601 UTC |

```json
{
  "id": "agg_001",
  "chat_group_id": "grp_001",
  "start_at": "2025-01-06T00:00:00Z",
  "end_at": "2025-01-12T23:59:59Z",
  "status": "running",
  "message_count": 0,
  "is_empty": false,
  "created_at": "2025-01-13T02:15:00Z"
}
```

**错误码**：`AUTH005`、`AUTH006`、`GRP003`、`AGG001`、`AGG002`

**幂等性**：写操作，支持 `Idempotency-Key` 请求头，相同 Key 在 24 小时内返回首次结果。

**业务规则**：`end_at` 与 `start_at` 跨度超过 31 天时返回 `AGG001`；同一群聊已有 `running` 任务时返回既有任务，不新建；范围内无消息时 `is_empty` 为 `true`，不生成草稿。

**状态流转**：新建 → `running`；执行成功 → `succeeded`；执行失败 → `failed`。

**并发控制**：同一 `chat_group_id` 上以数据库唯一约束保证同时只有一个 `running` 任务。

**关联验收标准**：AC-02、AC-03、AC-04

### POST /api/v1/aggregations/{aggregation_id}/retry

**用途**：汇总任务失败后人工触发重试。

**PRD 来源**：FR-03

**鉴权**：需要登录，角色 owner。

**路径参数**

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| aggregation_id | string | 是 | 汇总任务 id |

**响应**

## 附 A 枚举值汇总

| 枚举 | 取值 | 说明 |
| --- | --- | --- |
| 汇总任务状态 `aggregation.status` | `running` / `succeeded` / `failed` | 汇总任务生命周期状态 |
| 周报草稿状态 `report.status` | `draft` / `editing` / `exported` | 草稿初始为 `draft`；进入编辑置 `editing`；导出成功置 `exported`；导出失败回落到 `editing` |

| 用户角色 `user.role` | `owner` / `member` | `owner` 可绑定 / 解绑群聊、编辑草稿；`member` 只读自己被汇总到的条目 |
