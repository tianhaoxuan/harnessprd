# 群聊周报助手 · 总控提示词

## 项目定位

群聊周报助手是一个 Web 网站。它把团队群聊里的进展、决策、阻塞信息自动汇总为按人 / 项目组织的周报草稿，技术负责人只需少量修改即可导出到飞书，把撰写耗时从约 2 小时降到 10 分钟以内。

目标用户：20 人以下创业团队的技术负责人，兼做项目管理。

## 技术栈与版本

| 层 | 选型 |
| --- | --- |
| 前端 | React 18 + TypeScript 5，Vite 构建 |
| 后端 | Python 3.11 + FastAPI |
| 数据库 | PostgreSQL 15 |
| 鉴权 | JWT（`Authorization: Bearer <jwt_token>`） |
| 部署 | Docker 容器化，内网服务器 |

## 目录结构

```

├── frontend/
│   ├── src/
│   │   ├── pages/          # 登录页 / 表单页 / 汇总进度页 / 周报草稿页 / 导出历史页
│   │   ├── components/     # 通用组件
│   │   ├── api/            # 接口调用封装
│   │   └── types/          # 与接口文档一致的 TS 类型
```

## 代码规范

- 前后端分离，接口先定契约再实现。
- 后端字段命名 `snake_case`，前端类型字段与接口文档逐字一致。
- 时间统一 ISO 8601 + UTC，如 `2025-01-13T02:15:00Z`。
- 空值返回 `null`，不省略字段。
- 关键路径补测试。

## 视觉与交互约定

本次无该维度输入，待补充 `[待确认]`。

## 数据约定

- 主键为字符串，形如 `usr_001` / `grp_001` / `agg_001` / `rpt_001` / `exp_001`。
- 列表接口统一分页：`page`（从 1 起）+ `page_size`（默认 20，上限 100），响应为 `{ items, page, page_size, total }`。
- 写操作支持 `Idempotency-Key` 请求头，相同 Key 在 24 小时内返回首次结果。

## 错误处理约定

统一错误体：

```json
{
  "code": "RPT001",
  "message": "时间范围超过 31 天",
  "detail": null
}
```

状态码分界：400 请求不合法 / 401 未登录或凭证失效 / 403 无权限 / 404 资源不存在 / 409 状态或并发冲突 / 422 业务校验不通过 / 429 外部依赖限流 / 502 外部依赖失败 / 500 服务内部错误。

## 安全与合规约定

本次无该维度输入，待补充 `[待确认]`。

## 硬性禁止事项

- 禁止把密码明文落库，只存哈希。
- 禁止把飞书应用凭证下发到前端。
- 禁止引入接口文档未定义的接口路径或字段名。
- 禁止使用 SSE / WebSocket，汇总进度通过轮询 `GET /api/v1/aggregations/{id}` 获取。
- 禁止把数据传出内网。

## 术语表

| 术语 | 含义 |
| --- | --- |
| owner | 群聊归属人，可绑定 / 解绑群聊、编辑草稿、导出到飞书 |
| member | 只读自己被汇总到的条目，不能改他人草稿 |
| 汇总任务 | 对某群聊某时间范围消息的汇总，状态 `running` / `succeeded` / `failed` |
| 周报草稿 | 基于汇总结果生成的草稿，状态 `draft` / `editing` / `exported` |
| 分组维度 | `person`（按人）/ `project`（按项目） |

# 群聊周报助手 · 数据层提示词

## 目标

把接口文档第 4 章的数据模型落成 PostgreSQL 表、索引与迁移脚本。

## 实体与字段

### 用户 `users`

| 字段 | 类型 | 必填 | 唯一 | 默认值 | 说明 |
| --- | --- | --- | --- | --- | --- |
| `id` | string | 是 | 是 | 无 | 主键，形如 `usr_001` |
| `name` | string | 是 | 否 | 无 | 姓名 |
| `email` | string | 是 | 是 | 无 | 邮箱，登录账号 |
| `password_hash` | string | 是 | 否 | 无 | 密码哈希，不落明文 |
| `created_at` | string | 是 | 否 | 无 | 创建时间，ISO 8601 |

索引：`email` 唯一索引。

### 群聊配置 `chat_groups`

| 字段 | 类型 | 必填 | 唯一 | 默认值 | 说明 |
| --- | --- | --- | --- | --- | --- |
| `id` | string | 是 | 是 | 无 | 主键，形如 `grp_001` |
| `name` | string | 是 | 否 | 无 | 群聊名称 |
| `owner_id` | string | 是 | 否 | 无 | 归属人，外键 → `users.id` |
| `created_at` | string | 是 | 否 | 无 | 创建时间，ISO 8601 |

索引：`owner_id` 普通索引。

### 汇总任务 `aggregations`

| 字段 | 类型 | 必填 | 唯一 | 默认值 | 说明 |
| --- | --- | --- | --- | --- | --- |
| `id` | string | 是 | 是 | 无 | 主键，形如 `agg_001` |
| `chat_group_id` | string | 是 | 否 | 无 | 外键 → `chat_groups.id` |
| `owner_id` | string | 是 | 否 | 无 | 触发人，外键 → `users.id` |
| `start_at` | string | 是 | 否 | 无 | 汇总范围起，ISO 8601 |
| `end_at` | string | 是 | 否 | 无 | 汇总范围止，ISO 8601 |
| `message_count` | integer | 是 | 否 | `0` | 范围内消息数 |
| `status` | string | 是 | 否 | `running` | 见枚举全集 |
| `retry_count` | integer | 是 | 否 | `0` | 重试次数，不限上限 |
| `error_message` | string | 否 | 否 | `null` | 失败原因 |
| `created_at` | string | 是 | 否 | 无 | 创建时间，ISO 8601 |

索引：`chat_group_id` + `status` 联合索引（用于并发去重）。

### 周报草稿 `weekly_reports`

| 字段 | 类型 | 必填 | 唯一 | 默认值 | 说明 |
| --- | --- | --- | --- | --- | --- |
| `id` | string | 是 | 是 | 无 | 主键，形如 `rpt_001` |
| `aggregation_id` | string | 是 | 否 | 无 | 外键 → `aggregations.id` |
| `owner_id` | string | 是 | 否 | 无 | 归属人，外键 → `users.id` |
| `group_by` | string | 是 | 否 | `person` | 组织维度，见枚举全集 |
| `content` | object | 是 | 否 | 无 | 草稿正文，按人 / 项目组织的结构化内容 |
| `status` | string | 是 | 否 | `draft` | 见枚举全集 |
| `created_at` | string | 是 | 否 | 无 | 创建时间，ISO 8601 |
| `updated_at` | string | 是 | 否 | 无 | 更新时间，ISO 8601 |

索引：`aggregation_id` 普通索引，`owner_id` 普通索引。

### 导出记录 `exports`

| 字段 | 类型 | 必填 | 唯一 | 默认值 | 说明 |
| --- | --- | --- | --- | --- | --- |
| `id` | string | 是 | 是 | 无 | 主键，形如 `exp_001` |
| `report_id` | string | 是 | 否 | 无 | 外键 → `weekly_reports.id` |
| `user_id` | string | 是 | 否 | 无 | 操作人，外键 → `users.id` |
| `target` | string | 是 | 否 | `feishu` | 导出目标，见枚举全集 |
| `document_url` | string | 否 | 否 | `null` | 飞书文档链接 |
| `status` | string | 是 | 否 | `pending` | 见枚举全集 |
| `created_at` | string | 是 | 否 | 无 | 创建时间，ISO 8601 |

索引：`user_id` 普通索引，`report_id` 普通索引。

## 实体关系

- `users` 1 : N `chat_groups`（owner）
- `chat_groups` 1 : N `aggregations`
- `aggregations` 1 : N `weekly_reports`
- `weekly_reports` 1 : N `exports`

## 枚举全集

| 枚举 | 取值 | 说明 |
| --- | --- | --- |
| `aggregation.status` | `running` / `succeeded` / `failed` | 汇总任务生命周期状态 |
| `report.status` | `draft` / `editing` / `exported` | 草稿初始为 `draft`；进入编辑置 `editing`；导出成功置 `exported`；导出失败回落到 `editing` |
| `report.group_by` | `person` / `project` | 按人组织 / 按项目组织 |
| `user.role` | `owner` / `member` | `owner` 可绑定 / 解绑群聊、编辑草稿；`member` 只读自己被汇总到的条目 |
| `export.target` | `feishu` | 本期唯一导出目标 |
| `export.status` | `pending` / `succeeded` / `failed` | 导出记录状态 |

## 级联规则

| 父表 | 子表 | 删除父记录时 |
| --- | --- | --- |
| `users` | `chat_groups` | 禁止删除（RESTRICT），需先解绑群聊 |
| `chat_groups` | `aggregations` | 禁止删除（RESTRICT） |
| `aggregations` | `weekly_reports` | 禁止删除（RESTRICT） |
| `weekly_reports` | `exports` | 禁止删除（RESTRICT） |

本期不提供删除接口，级联规则仅用于约束数据库层，防止误删导致孤儿记录。

## 迁移与种子数据

迁移脚本放在 `backend/migrations/`，按编号顺序执行：

```sql
-- 0001_create_users.sql
CREATE TABLE users (
  id            TEXT PRIMARY KEY,
  name          TEXT NOT NULL,
  email         TEXT NOT NULL,
  password_hash TEXT NOT NULL,
  created_at    TIMESTAMPTZ NOT NULL
);
CREATE UNIQUE INDEX ux_users_email ON users (email);
```

```sql
-- 0002_create_chat_groups.sql
CREATE TABLE chat_groups (
  id         TEXT PRIMARY KEY,
  name       TEXT NOT NULL,
  owner_id   TEXT NOT NULL REFERENCES users (id) ON DELETE RESTRICT,
  created_at TIMESTAMPTZ NOT NULL
);
CREATE INDEX ix_chat_groups_owner_id ON chat_groups (owner_id);
```

```sql
-- 0003_create_aggregations.sql
CREATE TABLE aggregations (
  id            TEXT PRIMARY KEY,
  chat_group_id TEXT NOT NULL REFERENCES chat_groups (id) ON DELETE RESTRICT,
  owner_id      TEXT NOT NULL REFERENCES users (id) ON DELETE RESTRICT,
  start_at      TIMESTAMPTZ NOT NULL,
  end_at        TIMESTAMPTZ NOT NULL,
  message_count INTEGER NOT NULL DEFAULT 0,
  status        TEXT NOT NULL DEFAULT 'running',
  retry_count   INTEGER NOT NULL DEFAULT 0,
  error_message TEXT,
  created_at    TIMESTAMPTZ NOT NULL
);
CREATE INDEX ix_aggregations_group_status ON aggregations (chat_group_id, status);
```

```sql
-- 0004_create_weekly_reports.sql
CREATE TABLE weekly_reports (
  id             TEXT PRIMARY KEY,
  aggregation_id TEXT NOT NULL REFERENCES aggregations (id) ON DELETE RESTRICT,
  owner_id       TEXT NOT NULL REFERENCES users (id) ON DELETE RESTRICT,
  group_by       TEXT NOT NULL DEFAULT 'person',
  content        JSONB NOT NULL,
  status         TEXT NOT NULL DEFAULT 'draft',
  created_at     TIMESTAMPTZ NOT NULL,
  updated_at     TIMESTAMPTZ NOT NULL
);
CREATE INDEX ix_weekly_reports_aggregation_id ON weekly_reports (aggregation_id);
CREATE INDEX ix_weekly_reports_owner_id ON weekly_reports (owner_id);
```

```sql
-- 0005_create_exports.sql
CREATE TABLE exports (
  id           TEXT PRIMARY KEY,
  report_id    TEXT NOT NULL REFERENCES weekly_reports (id) ON DELETE RESTRICT,
  user_id      TEXT NOT NULL REFERENCES users (id) ON DELETE RESTRICT,
  target       TEXT NOT NULL DEFAULT 'feishu',
  document_url TEXT,
  status       TEXT NOT NULL DEFAULT 'pending',
  created_at   TIMESTAMPTZ NOT NULL
);
CREATE INDEX ix_exports_user_id ON exports (user_id);
CREATE INDEX ix_exports_report_id ON exports (report_id);
```

- `POST /api/v1/aggregations`
- `GET /api/v1/aggregations/{aggregation_id}`
- `POST /api/v1/aggregations/{aggregation_id}/retry`

## 约束

- `end_at - start_at > 31 天` 返回 `AGG001`（422）；`end_at` 早于 `start_at` 返回 `AGG002`（422）。

- 仅 `failed` 状态可重试，重试次数不限；非 `failed` 返回 `AGG004`（409）。
- 汇总 500 条消息须在 30 秒内返回。
- 进度页用轮询 `GET /api/v1/aggregations/{id}`，间隔 2 秒，不使用 SSE / WebSocket；`succeeded` 或 `failed` 后停止轮询。
- 时间范围选择器前端就地校验 31 天上限，超限不提交并提示。

- `GET /api/v1/exports`

## 约束

- 本步只补测试与自检报告，**不修改任何业务实现**。若测试暴露实现缺陷，只记录到 `docs/verify-report.md`，不就地改代码。
- 测试必须打真实 PostgreSQL（`docker-compose up -d db`），禁止用 SQLite 替代，因为 `aggregations` 的并发去重依赖 `chat_group_id` + `status` 联合索引。
- 飞书开放平台在测试中一律用 `httpx.MockTransport` 打桩，禁止真实调用；限流场景返回 HTTP 429，失败场景返回 HTTP 502。
- 每个测试用例的命名格式为 `test_<AC编号小写>_<场景>`，例如 `test_ac03_range_over_31_days_rejected`。
- 断言必须落在接口文档第 5 章的错误码上，禁止只断言 HTTP 状态码。
- 时间字段一律用 ISO 8601 + UTC 断言，禁止断言本地时区字符串。
