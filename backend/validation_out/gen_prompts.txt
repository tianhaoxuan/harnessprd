# 群聊周报助手 · 项目总控

## 项目定位

面向 20 人以下创业团队的技术负责人（兼项目管理）。团队群聊信息散落，每周人工翻聊天记录拼周报要花两小时且容易漏掉重要进展。本工具自动汇总指定企业微信群的消息，按人生成周报草稿，支持人工修改后导出，供复制到飞书群。

平台形态：Web 网站。全新项目，无历史包袱。

## 技术栈与版本

| 层 | 选型 |
| --- | --- |
| 前端 | React |
| 后端 | FastAPI |
| 数据库 | PostgreSQL |
| 接口风格 | RESTful |
| 鉴权 | JWT |
| 第三方服务 | 企业微信（拉取群消息）、GitHub OAuth（登录） |

## 目录结构

前端按 features 分目录：

```
frontend/src/features/<feature-name>/
```

后端按接口资源分模块，与接口文档的路径前缀对应。

## 数据约定

- 实体与字段以接口文档第 4 章为准，命名逐字一致。
- 核心实体：用户（id、昵称、所属团队）、周报（id、周期、正文、状态、创建人）。
- 时间范围默认最近 7 天。
- 时间与时区：时间范围按用户所在时区解释 `[待确认]`。

## 错误处理约定

- 接口入参必须校验，校验失败返回 422。
- 群消息拉取失败时跳过该群并提示，不整体失败。
- 企业微信授权失效时提示重新授权，不整体失败。
- 第三方登录失败时提示，不进入工具。
- 保存失败时保留用户输入，允许重试。

## 视觉与交互约定

简洁克制，参考 Linear、Notion。主流程为单页单点操作：选群 → 选时间范围 → 生成 → 编辑 → 导出。

## 安全与合规约定

本次无该维度输入，待补充。
