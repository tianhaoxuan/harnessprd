# 群聊周报助手 PRD

## 1. 产品概述

| 项目 | 内容 |
| --- | --- |
| 产品名称 | 群聊周报助手 |
| 核心问题 | 团队群聊里的进展、决策、阻塞信息散落各处，每周需要人工翻聊天记录拼周报，一次约两小时，且容易遗漏关键信息。期望通过自动汇总群聊消息并按人 / 项目生成周报草稿，把每周拼周报的时间从约两小时压缩到以人工修改措辞为主。 |
| 目标用户 | 20 人以下创业团队的技术负责人，兼做项目管理 |
| 平台 | Web 网站。需处理浏览器登录态与账号密码注册登录；屏幕宽度以 1280 起为设计基准。 |

## 2. 功能需求

### MVP 功能

| 编号 | 功能 | 说明 | 优先级 | 边界条件 |
| --- | --- | --- | --- | --- |
| FR-01 | 账号注册登录 | 用户以账号密码注册并登录，登录后进入主场景动线。输入为账号与密码，输出为已登录会话。 | P0 | 账号已存在时注册失败并提示；密码错误时登录失败并提示；未登录访问受保护页面时跳转登录页。 |
| FR-02 | 绑定群聊并汇总 | 技术负责人绑定一个群聊并选定时间范围，触发汇总。输入为群聊标识与时间范围，输出为一条汇总任务及其结果。 | P0 | 时间跨度超过 31 天时拒绝并提示；群聊在范围内没有消息时给出空态而不是空草稿；同一群聊并发触发两次汇总时，第二次返回既有任务。 |
| FR-03 | 生成周报草稿 | 按人 / 项目组织汇总结果，生成周报草稿。输入为汇总任务结果，输出为草稿内容。 | P0 | 汇总结果为空时不生成草稿，返回空态。 |
| FR-04 | 导出到飞书 | 将草稿导出为飞书文档，导出完成后在飞书侧收到文档链接。输入为草稿内容，输出为飞书文档链接。 | P0 | 飞书侧限流（每分钟 5 次）时需退避重试；导出失败时保留草稿并提示失败原因。 |
| FR-05 | 人工编辑草稿 | 在草稿页手工调整措辞，保存后写回草稿。输入为编辑后的文本，输出为更新后的草稿。 | P1 | 保存时校验不通过则不写回并提示；编辑内容为空时不允许保存。 |
| FR-06 | 导出历史记录 | 查看历史导出记录，包含导出时间与飞书文档链接。 | P1 | 无历史记录时给出空态。 |

优先级说明：P0 与 P1 分级来自对话确认的优先级分级（S3）；P2 项（按项目维度组织草稿、多群对比）列入未来功能，不在本期范围。

### 验收标准

| 编号 | 对应功能 | 验收标准 |
| --- | --- | --- |
| AC-01 | FR-01 | 给定未注册的账号，当提交注册并填写合法账号密码时，则注册成功并可登录；给定已存在的账号，当再次注册时，则返回失败并提示账号已存在。 |
| AC-02 | FR-01 | 给定未登录状态，当访问受保护页面时，则跳转至登录页。 |
| AC-03 | FR-02 | 给定已登录的 owner，当绑定群聊并选定不超过 31 天的时间范围触发汇总时，则生成一条汇总任务并返回结果。 |
| AC-04 | FR-02 | 给定选定的时间范围超过 31 天，当触发汇总时，则拒绝并提示时间跨度过大。 |
| AC-05 | FR-02 | 给定群聊在选定范围内没有消息，当触发汇总时，则返回空态而非空草稿。 |
| AC-06 | FR-02 | 给定同一群聊已有进行中的汇总任务，当再次触发汇总时，则第二次返回既有任务而不新建任务。 |
| AC-07 | FR-03 | 给定汇总任务已有结果，当生成周报草稿时，则草稿按人 / 项目组织呈现。 |
| AC-08 | FR-03 | 给定汇总结果为空，当生成周报草稿时，则不生成草稿并返回空态。 |
| AC-09 | FR-04 | 给定一份草稿，当导出到飞书成功时，则在飞书侧收到文档链接。 |
| AC-10 | FR-04 | 给定飞书侧返回限流（每分钟 5 次），当导出请求被限流时，则按退避策略重试。 |
| AC-11 | FR-05 | 给定草稿页已打开，当修改措辞并保存且校验通过时，则写回草稿并提示已保存。 |
| AC-12 | FR-06 | 给定存在历史导出记录，当打开导出历史时，则列出导出时间与飞书文档链接；无记录时给出空态。 |

### 未来功能

- 多群对比

## 3. 页面设计

### 页面列表

| 页面名 | 用途 | 路径 | 支撑功能 |
| --- | --- | --- | --- |
| 登录 / 注册页 | 账号密码注册与登录 | `/login` | FR-01 |
| 群聊绑定与汇总页 | 绑定群聊、选定时间范围并触发汇总 | `/groups` | FR-02 |
| 周报草稿页 | 查看按人 / 项目组织的草稿并手工调整措辞 | `/reports/:id/edit` | FR-03、FR-05 |
| 导出历史页 | 查看历史导出记录与飞书文档链接 | `/exports` | FR-06 |

页面清单由功能反推，待确认。

### 模块划分

- 登录 / 注册页：登录表单模块（账号密码输入与提交）、注册表单模块（新账号创建）。
- 群聊绑定与汇总页：群聊绑定模块（选择并绑定群聊）、时间范围选择模块（选定汇总区间）、汇总触发模块（发起汇总并展示任务状态）。
- 周报草稿页：草稿展示模块（按人 / 项目组织呈现）、编辑模块（修改措辞）、导出模块（导出到飞书并展示文档链接）。
- 导出历史页：历史列表模块（列出导出时间与飞书文档链接）。

### 关键交互

- 在登录 / 注册页提交合法账号密码，登录成功并进入主场景动线。
- 在群聊绑定与汇总页选定时间范围并触发汇总，时间跨度超过 31 天时拒绝并提示。
- 在群聊绑定与汇总页对同一群聊并发触发汇总，第二次返回既有任务。
- 在周报草稿页点击保存且校验通过，写回草稿并提示已保存。
- 在周报草稿页点击导出，导出成功后展示飞书文档链接；被限流时退避重试。

## 4. 技术规格

### 认证与权限

认证方式：账号密码注册登录。

| 角色 | 可见范围 |
| --- | --- |
| owner | 可绑定 / 解绑群聊 |
| member | 只读自己被汇总到的条目 |

### 数据与存储

数据实体清单：本次无该维度输入，待补充 `[待确认]`。

持久化范围：需要长期保存用户数据，使用 PostgreSQL。

### 前后端技术

前端 React + TypeScript，后端 Python FastAPI，数据库 PostgreSQL。

### 部署方式

部署在内网服务器，不上公有云。

### 外部依赖

飞书开放平台（导出周报文档）。

## 5. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 性能 | 汇总 500 条消息 30 秒内返回；单团队 20 人以内，消息量每天数百条。 |
| 安全 | 手机号必须加密存储；需要操作审计日志；数据不能出境。 |
| 可用性 | 服务可用性按工作时段 99% 要求。 |
| 兼容性 | 支持 Chrome / Edge 最近两个大版本，屏幕宽度 1280 起。 |
